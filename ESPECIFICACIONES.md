# Especificaciones del Proyecto Final — Catálogo de Productos (MVP)

> MVP de **una sola tabla** (`products`) con backend FastAPI, frontend React + Vite + Tailwind con visor 3D, despliegue continuo y herramientas colaborativas.

---

## 1. Objetivo

Construir y desplegar una aplicación web que permita **registrar y listar productos**, persistidos en una base de datos relacional, consumidos por un frontend con un **componente 3D interactivo**, e integrando herramientas de IA, colaboración y revisión visual.

## 2. Alcance (MVP)

| Incluido | Fuera de alcance |
|---|---|
| Tabla única `products` | Autenticación de usuarios |
| `GET` y `POST` de productos | Editar / eliminar (`PUT` / `DELETE`) — opcional extra |
| Formulario de alta (nombre, precio, stock, imagen) | Carrito, pagos, pedidos |
| Listado en tabla o grid | Relaciones entre tablas |
| Visor 3D del producto destacado | Subida de imágenes (solo URL) |

## 4. Modelo de datos

Tabla `products`:

| Columna | Tipo (Postgres) | Tipo (SQLite) | Restricciones |
|---|---|---|---|
| `id` | `bigint identity` | `INTEGER` | PK, autoincremental |
| `name` | `text` | `TEXT` | `NOT NULL` |
| `price` | `numeric` | `REAL` | `NOT NULL`, ≥ 0 |
| `stock` | `integer` | `INTEGER` | `DEFAULT 0`, ≥ 0 |
| `image_url` | `text` | `TEXT` | opcional |
| `created_at` | `timestamptz` | `DATETIME` | `DEFAULT now()` |

### SQL para Supabase

```sql
create table products (
  id bigint generated by default as identity primary key,
  name text not null,
  price numeric not null,
  stock integer default 0,
  image_url text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

alter table products enable row level security;

create policy "Cualquiera puede ver los productos"
  on products for select to public using (true);
```

> Nota: la política RLS afecta a la API REST de Supabase. FastAPI se conecta directamente con el usuario `postgres`, que **no** está sujeto a RLS, por eso el `POST` funciona desde el backend.

## 5. Base de datos: ¿Supabase o SQLite?

**Sí, se puede reemplazar Supabase por SQLite**, y gracias a SQLAlchemy el cambio es solo la variable `DATABASE_URL`. Pero hay un límite importante en producción:

| Criterio | SQLite | Supabase (Postgres) |
|---|---|---|
| Configuración | Ninguna (un archivo `products.db`) | Crear proyecto y copiar connection string |
| Desarrollo local | ✅ Ideal | ✅ Funciona |
| Producción en **Render gratuito** | ❌ **Los datos se pierden** en cada redeploy/reinicio (el disco es efímero; el disco persistente es de pago) | ✅ Datos persistentes |
| Ver datos en panel web | No (usar DB Browser for SQLite) | Sí (Table Editor) |
| Rúbrica del curso | ⚠️ Pide "persiste registros reales en **Supabase**" | ✅ Cumple |

**Recomendación:** usar **SQLite en local** (rápido, sin credenciales) y **Supabase en Render** (producción). El mismo código sirve para ambos. Si el docente acepta SQLite en producción, habría que usar un disco persistente de Render (plan pago) o asumir que los datos se reinician.

### `.env` según entorno

```env
# Local (SQLite) — no requiere nada más
DATABASE_URL=sqlite:///./products.db

# Producción (Supabase, Session Pooler — compatible con IPv4 / Render)
DATABASE_URL=postgresql+psycopg2://postgres.<PROJECT_REF>:<PASSWORD>@aws-0-<REGION>.pooler.supabase.com:5432/postgres
```

> Usar el **Session Pooler** (`*.pooler.supabase.com`) y no la conexión directa `db.<ref>.supabase.co`, que solo funciona por IPv6 y suele fallar desde Render y redes domésticas.

### `database.py` (compatible con SQLite y Postgres)

```python
import os
from sqlalchemy import create_engine
from sqlalchemy.orm import declarative_base, sessionmaker
from dotenv import load_dotenv

load_dotenv()

# Si no hay DATABASE_URL, se usa SQLite local
DATABASE_URL = os.getenv("DATABASE_URL", "sqlite:///./products.db")

# SQLite necesita este flag para usarse desde varios hilos (FastAPI)
connect_args = {"check_same_thread": False} if DATABASE_URL.startswith("sqlite") else {}

engine = create_engine(DATABASE_URL, connect_args=connect_args, pool_pre_ping=True)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

### `models.py`

```python
from sqlalchemy import Column, Integer, String, Float, DateTime, func
from database import Base

class Product(Base):
    __tablename__ = "products"

    id = Column(Integer, primary_key=True, index=True)
    name = Column(String, nullable=False)
    price = Column(Float, nullable=False)
    stock = Column(Integer, default=0, nullable=False)
    image_url = Column(String, nullable=True)
    created_at = Column(DateTime(timezone=True), server_default=func.now())
```

### `schemas.py`

```python
from datetime import datetime
from typing import Optional
from pydantic import BaseModel, ConfigDict, Field

class ProductBase(BaseModel):
    name: str = Field(min_length=1)
    price: float = Field(ge=0)
    stock: int = Field(default=0, ge=0)
    image_url: Optional[str] = None

class ProductCreate(ProductBase):
    pass

class ProductResponse(ProductBase):
    id: int
    created_at: Optional[datetime] = None
    model_config = ConfigDict(from_attributes=True)
```

### `main.py`

```python
import os
from typing import List

import requests
from fastapi import FastAPI, Depends, status
from fastapi.middleware.cors import CORSMiddleware
from sqlalchemy.orm import Session

import models, schemas
from database import engine, get_db

models.Base.metadata.create_all(bind=engine)

app = FastAPI(title="API de Catálogo de Productos", version="1.0.0")

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],   # En producción: ["https://mi-tienda-productos.vercel.app"]
    allow_methods=["*"],
    allow_headers=["*"],
)

SLACK_WEBHOOK_URL = os.getenv("SLACK_WEBHOOK_URL")

@app.get("/api/v1/products", response_model=List[schemas.ProductResponse], tags=["Productos"])
def list_products(db: Session = Depends(get_db)):
    return db.query(models.Product).order_by(models.Product.id.desc()).all()

@app.post("/api/v1/products", response_model=schemas.ProductResponse,
          status_code=status.HTTP_201_CREATED, tags=["Productos"])
def create_product(product: schemas.ProductCreate, db: Session = Depends(get_db)):
    nuevo = models.Product(**product.model_dump())
    db.add(nuevo)
    db.commit()
    db.refresh(nuevo)

    if SLACK_WEBHOOK_URL:  # Notificación opcional a Slack
        try:
            requests.post(SLACK_WEBHOOK_URL, timeout=3,
                          json={"text": f"🆕 Nuevo producto: *{nuevo.name}* — ${nuevo.price} (stock {nuevo.stock})"})
        except requests.RequestException:
            pass  # Slack caído no debe romper el alta

    return nuevo
```

> Nota: `allow_credentials=True` junto con `allow_origins=["*"]` no es válido para navegadores; como la app no usa cookies, se omite.

### Contrato de la API

| Método | Ruta | Body | Respuesta |
|---|---|---|---|
| `GET` | `/api/v1/products` | — | `200 OK` — lista de productos |
| `POST` | `/api/v1/products` | `{ "name", "price", "stock", "image_url?" }` | `201 Created` — producto con `id` |
| `GET` | `/docs` | — | Swagger UI |

Errores de validación devuelven `422 Unprocessable Entity`.

### Servicio de API (`src/api.js`)

```javascript
const API = import.meta.env.VITE_API_URL;

export async function getProducts() {
  const res = await fetch(`${API}/api/v1/products`);
  if (!res.ok) throw new Error("Error al cargar productos");
  return res.json();
}

export async function createProduct(data) {
  const res = await fetch(`${API}/api/v1/products`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(data),
  });
  if (!res.ok) throw new Error("Error al crear producto");
  return res.json();
}
```

### Visor 3D (`src/Product3DViewer.jsx`)

```jsx
import { Canvas } from "@react-three/fiber";
import { OrbitControls } from "@react-three/drei";

function Box3D({ color = "#4f46e5" }) {
  return (
    <mesh rotation={[0.4, 0.6, 0]}>
      <boxGeometry args={[2, 2, 2]} />
      <meshStandardMaterial color={color} />
    </mesh>
  );
}

export function Product3DViewer({ product }) {
  return (
    <div className="h-64 w-full bg-slate-900 rounded-lg overflow-hidden my-4">
      <Canvas>
        <ambientLight intensity={0.5} />
        <directionalLight position={[2, 5, 2]} />
        <Box3D />
        <OrbitControls enableZoom={false} autoRotate />
      </Canvas>
      <p className="text-center text-xs text-slate-400 py-1">
        {product?.name ?? "Producto destacado"} — rotar con el cursor
      </p>
    </div>
  );
}
```
